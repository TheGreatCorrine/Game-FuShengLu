# 12 — Phase 2A.1 确定设计与开发约束（GDD v1.3）

> 状态：**设计决议已确认；实现与数值分布尚待 Stage A 审核及 Stage B 开发。** 这份文件用于覆盖旧文档中可能与下述规则冲突的默认做法，但不替代其他 GDD 的历史规则、叙事和工程规范。

## 1. 用户已确定的正式决议

| 主题 | 决议 | 本轮范围 |
| --- | --- | --- |
| 年度行动 | 成年常规每年 **2 次主动行动**；童年由年龄和家庭限制/安排 | Stage A 定义、Stage B 核准后开发 |
| 事件回应 | 重大突发事件回应通常不占主动额度；会产生独立资源/风险代价 | 设计/校准 |
| 市集 | 统一 UI 名称「市集」，常规每年最多访问一次；单次可购买多件 | Stage A 设计；功能后续 |
| 天资天性 | 悟性、通情、勤勉、韧性，以及部分人物可能拥有的专长禀赋；均为隐藏状态 | Stage A 属性审计与设计，择机实现 |
| 关系呈现 | 人物志显示「亲近」「尚可」「疏远」「彼此不睦」「尚不清楚」等模糊状态；不显示精确值 | 设计/适度 UI 校准 |
| 婚姻自主权 | 受朝代、时期、地区、家族权力、个人条件与人物意愿动态制约；父母可推动或强势安排 | Stage A 设计；基础平衡，深度机制 Phase 2B/C |
| 解除婚姻 | 主角可尝试提出分开；**不保证法律可行或成功**；NPC 可反对，关系变化因人而异 | Stage A 设计，历史核实后分期实现 |
| 经济 | 不以欠债为默认命运；共同生活的家户按实际成员结算；分家后旧债不自动转移 | 本阶段优先校准 |
| NPC 自主性 | 重要 NPC 有独立目标、关系、经历与进展；玩家不直接控制他人 | Phase 2B 重点 |

## 2. 有限主动行动系统

- 每个游戏年，成年主角通常拥有两项主动行动。例如：主动学习、习艺、特定谋生尝试、拜访亲友、游历、去市集、主动发起重要协商。
- **自然谋生不是必须每年按一次“工作”才有收入**：劳动、家户生产、健康、社会关系与 NPC 年度演进仍按模拟时钟结算。
- 一项主动行动代表占用全年部分注意力/机会，不要求等同一整年的每一天。对于能否重复同类动作（如两次学习），Stage A 应提出防刷机制和设计理由；不要默许无限练习。
- 被动事件响应不使用常规主动行动额度，但可能要求实际物资、技能、时间与关系成本。死亡/无行动能力时不能再用行动额度。
- 成年资格与历史成丁规则需分离：这里的“成年”是**玩法行动资格分组**，不应无依据宣称等同西汉法律成人年龄。
- 童年通常由家庭/监护人安排大部分事务；随着年龄增长主角可提出更多请求，是否获准由相关 NPC 与历史规则裁定。

## 3. 市集（设计占位，暂不开发完整系统）

- 「市集」是每年最多一次的主动访问，不是无限刷钱/经验/关系的商店。
- 一次访问可查看品类并选择多项合理商品，交易**确认后**才扣除价格和本年度访问机会；取消/纯浏览不应无解释地扣钱。
- 商品未来可包括衣物、日用品、礼物、笔墨书简、劳动工具、药材等，必须有实际用途。价格与可得性依时间、地域、身份、当地供应及历史研究配置。
- 财物所有权必须尊重荷包与家户的分离；需要家户批准的大笔交易不可默认为主角直接支配。
- 不做现代购物车式无限采购、库存刷利、随机付费抽卡或无限交易漏洞。

## 4. 隐藏天资/天性/技能

- **悟性**：学习理解与适应能力，并非现代心理测量 IQ；对学习速度/新任务理解产生倾向性影响。
- **通情**：读懂情绪与社交线索的倾向，并非全知他人内心、也不等于人缘好。
- **勤勉**：日常持续投入的倾向；能被经历和环境缓慢影响，但不能通过每年固定加点刷满。
- **韧性**：面对挫折后的持续尝试与恢复策略；不保证免疫压力或创伤。
- **专长禀赋**：稀疏可选的特定领域学习亲和（如音律、算术、书写、工艺），并非每人必有；没有特殊天赋不意味着缺乏普通学习能力。
- 与通过教育/实践发展出的 **知识、技能、职业经验**，以及当下 **健康、社会地位、家庭资源** 分开。先审计现有 `talent`, `skill`, `practice` 与 NPC 人格字段，再做最小必要的兼容扩展。
- 玩家与重要 NPC 的隐藏禀赋由 seed 可复现生成；一般界面不显示确切数值，玩家通过表现、反馈、实际经历理解差异。
- 先天能力不包办命运，低悟性仍可通过努力、师长、资源与偶然机会取得成就，高悟性也可能无机会受教。

## 5. 婚姻、家庭意愿与关系

- 议亲、候选人生成、家庭商议、订立婚约（若适用）、成婚、婚后居住与解消婚姻为不同状态/阶段；具体过程须按时期核实。
- 角色可主动提议/反对，也可能在没主动行动时遭遇父母/监护人推动婚事。婚姻自主权由历史合法性、权力依赖、财产、性别、社会身份、家人性格和支持网络共同决定；不预设每个家长都尊重或忽视主角意愿。
- “和离”“休妻”“再嫁”等法律概念不能未经审校地套用于所有朝代；本版可以用非法律断言的「商议分开」等 UI 文案，并记录研究待办。
- 主角提出解除婚姻是**行动意图**而非结果；能否发起/成功、双方关系变化、居住与经济后果均由当前历史规则、NPC 意愿和家庭/子女处境决定。
- 可见的关系评价**不是**万能服从条：双方感情可能不同；也可能亲近却无法在重大利益上同意，或感情淡薄但愿意和平分开。事件记忆和长期行为必须影响关系。

## 6. 必须先校准的已知问题

1. 原经济公式导致多人家户中持续赤字与高债务率；按出生类型、成员结构、年龄、多种选择策略诊断原因，不以单一目标比例“刷数据”。
2. 婚事机会触发和成功率叠加导致偏晚、稀少；按实际存活且符合资格的人群计算议亲、谈判、成婚、未婚与再婚分布，依西汉史料与游戏目标校准。
3. 性别/出身/身份对教育、谋生、结亲、居住与权利的差异目前不足；优先审计缺口，Phase 2C 再开发大型路径内容。
4. 现有健康、`talent`、`skill`、`practice` 和 NPC 性格可能有闲置/重叠字段；先梳理实际读写与可见结果。
5. 事件必须有合格活人参与；修复“无病人也出现亲人染恙”等资格问题、重复选项、选项后果无由增加钱等 Bug。
6. 主界面不再常驻四类财务精确数字；优先显示健康、家境与个人可支配财物。明细进家户页。

## 7. 历史法度与后续查阅

- 法律规则是 `Historical Ruleset` 的组成部分，最终影响可选行动与事件资格，而非仅作背景文字。
- 区分**成文法、习惯、执行现实与非法胁迫**；债务责任、婚姻解除、继承及典卖人口等制度不得跨朝代套用。
- 未来可设计《当朝律令》或类似参考入口，但**不在 Phase 2A.1 实现**；来源不足不生成断言，更不启用严重人身胁迫事件。

## 8. 工程交付纪律与验收

- **Stage A：只审计、研究、做四张基础设计表 + 年度行动/市集表 + 隐藏天资表，列出设计者必须批准的数值和未决史料。** 可独立修复明显 Bug，但不得擅自做大规模平衡重构。
- **Stage B：设计者确认后**小步修改，通过固定 seed 和多套策略对照测试，证明贫穷/富裕、早婚/晚婚/不婚、教育与才华/努力、健康差异均有可解释的路径。
- **Phase 2B** 才深入做 NPC 自主人生线、双方家庭互动与婚姻冲突解决；**Phase 2C** 才系统落实社会身份×性别差异；市集完整 UI 与律令检索排后。
- 一切内容遵守纯前端、无云存档、无实时 AI 叙事、无需 CG 的既有边界。
