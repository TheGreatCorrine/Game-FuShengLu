# 08 — 西汉纵向切片：可直接交付开发的最小规格

## 1. 目的

用一个小型、端到端可运行的 demo 验证两条核心命题：**同史不同命**、**15 岁选择在 40 岁仍有影响**。这不是宣称实现了整个西汉，而是为内容扩展证明引擎结构。

## 2. 范围

- 世界：西汉、汉武帝时期的一个**待史料核定**出生窗口。
- 地区：关中、关东某地区、江南某地区（这里仅做广义地域占位；上线前替换为对应时段合法历史地理标识）。
- 家庭类型：自耕农、佃作家庭、商贾、地方官吏相关家庭（身份/财富须条件生成）。
- 性别：按对应制度规则分别配置生活可能性；不强迫每位玩家婚育。
- NPC：父母、手足、师傅/商贸伙伴或亲友；至少 5 个可被事件引用的角色，其中至少 2 人具备不同稳定性格与自主目标。
- 时钟：出生至死亡；至少支持年龄 15 和 40 的年谱观察。
- 内容：6–10 个完整事件模板、2 个延迟后果链、1 个历史地区冲击、1 个终局史实揭示，足够证明架构，但不是可发行内容量。

## 3. 示例历史冲击的安排

必须选择**与测试时间轴确实一致、史料可核验**的具体历史事件（可以是某项政策、战争影响或经济变化）。本文故意不替未研究的年份编造某场疫病/粮价数据；开发前用史料表选定一个节点。

测试要求：

- 地区甲和乙受到不同程度的直接冲击；丙可能没有明显直接冲击。
- 同一地区的两种家庭因资产/职业不同，后果不一样。
- 主角不会因为世界事件发生就被系统直接告知事件的现代标准名称。
- 终局报告揭示其对应历史事实与角色经历之间的因果链接，若角色没有受影响就应如实说明。

## 4. 两个因果链样例（虚构内容）

**链 A：15 岁离乡学艺**

```text
15: 选择离乡 -> 资源下降 + 地区迁徙 + 师傅关系 + 技能训练计划
18: 有机会完成学徒阶段，失败也可能出现
25: 技能/熟人网络影响职业事件资格
40: 经营路径或对家乡亲属的疏远，终局回顾标注 15 岁决定
```

**链 B：15 岁留家护产**

```text
15: 留家 -> 家庭关系增强 + 职业发展受限/延后
21: 有机会继承/守住一部分资源；也可能遇到经济波动
30: 家庭网络影响婚姻/家产变动
40: 收入、名声或亲属责任的持续后果，回顾标注选择来源
```

不要把两条链写成固定好坏结局；它们都由后续随机变量、地区冲击、家人行为决定。

## 5. 事件示例 JSON（游戏数据，不代表历史概率）

```json
{
  "id": "life.apprenticeship.leave_home",
  "category": "choice",
  "when": { "minAge": 15, "maxAge": 17 },
  "eligibility": [
    { "path": "player.alive", "op": "eq", "value": true },
    { "path": "family.availableResources", "op": "gte", "value": 10 }
  ],
  "weight": 8,
  "maxPerLife": 1,
  "choices": [
    {
      "id": "leave",
      "text": "离乡学艺",
      "immediateEffects": ["resource:-10", "flag:left_home_at_15"],
      "schedule": [
        { "afterYears": 3, "eventId": "life.apprenticeship.progress" },
        { "afterYears": 25, "eventId": "life.apprenticeship.long_echo" }
      ]
    },
    {
      "id": "stay",
      "text": "留家帮忙",
      "immediateEffects": ["relationship:family:+5", "flag:stayed_home_at_15"],
      "schedule": [{ "afterYears": 25, "eventId": "life.stay_home.long_echo" }]
    }
  ],
  "evidenceLevel": "gameplay"
}
```

以上效果字符串是内容样本，生产版本应使用强类型 Effect 对象与严格 validator，不直接对字符串执行任何表达式。

## 6. UI 最小屏幕

1. 朝代/时期选择（仅西汉可点，其他标「即将推出」）。
2. 随机出身页（地区、家世、性别、父母、家中资源）。
3. 年谱界面（人物视角事件、目前生活状态、下一段时间）。
4. 关键选择弹层（选择说明只用角色可能知道的信息）。
5. 人生终局（生平、15→40 回响、历史真相与来源、历史人物类比若有数据）。
6. 人物志（已知身份/职业、可观察性情、重要关系与经历；不显示隐藏性格和真实动机）；荷包/家庭资产摘要分离。

## 7. 自动化验收（必须）

```text
Given 同一个 canonical historical event 与同一时间
When 在不同地区、身份的角色身上推进模拟
Then 不应所有人得到同一个固定事件/伤害/知识通知

Given 角色 15 岁选择离乡
When 推进到 40 岁且没有提前死亡
Then life memory 仍有该选择；至少一条后果事件可回溯至它

Given NPC 已死
When 任意后续事件运行
Then 不得出现 NPC 作为存活行动者

Given 主角不具备史实信息渠道
When 世界触发历史节点
Then 可看到局部生活变化，但不能被强制剧透历史名称

Given 终局生成
When 展开历史揭秘
Then 史实、角色实际观察、关联因果与来源必须分栏呈现

Given 两名性格、利益、关系不同的父母
When 玩家提出同样请求（例如继续读书/推迟议亲）
Then 系统可产生不同的支持或拒绝结果；均保存原因标识，而不是只按单个好感阈值判断

Given 玩家多年未与某核心 NPC 互动
When 连续推进 5 个年份
Then 该 NPC 的年龄、健康、职业/目标或家庭经历按规则演化，且不会凭空重置为初次见面状态

Given 角色在适用制度下合法婚配
When 建立新的家户网络
Then 配偶与关键姻亲以唯一 ID 接入亲属图；居住、财产控制与人际权限根据时代条件结算，不能凭空复制资产

Given 玩家查看人物志
When 查看配偶、父母或姻亲
Then 只展示玩家可得的官职/职业、身份、观察与传闻，隐藏其精确野心/控制欲/目标数值
```

如果角色 40 岁前死亡，长期因果测试必须用受控种子或生存条件执行，不能通过强行让所有人长寿解决。

## 8. 首个工程 Sprint 的交付内容

- TypeScript 类型、统一历史年份编码、seedable RNG、状态机、事件条件过滤器。
- 1 个历史冲击数据文件 + 至少 3 个地区的不同效果。
- 2 条带 scheduler 的 25 年延迟故事链。
- UI 最小可见原型、人物志、个人荷包/家产分离与终局 reveal。
- 一键运行自动化不变量测试和 1000+ seed 的模拟质量报告（数字为建议门槛，不代表统计学真实性）。

**Done = 所有核心验收通过且能一局走完**。视觉美术、AI、复杂 NPC、跨朝代内容不阻塞切片完成。

## 9. v1.1 NPC 微型场景（验收样例，不指代真实史实）

**场景 A · 家长意志**：玩家 13–16 岁提出“继续学艺而非立即议亲”。同一制度、同一资产背景下，务实而信任子女的父母更可能同意；看重门第且受债务压力的父母可能拒绝。绝不将同意设为唯一“好结局”。

**场景 B · 夫家是活家庭**：玩家若满足时代身份与婚姻条件，在某一分支合法婚配，配偶有真实职业/可能官职、追求、家产关系；姻亲仅在确实存活且具有家族关系时生成/加入。婚配后的下一年，即使玩家不理会配偶，配偶也会按自身目标学习、劳动或改变状态。若原生家庭仍在，双方家庭关系都保持。

**场景 C · 信息差**：媒人称配偶“温和稳重”，此仅为 `reported`，不可写成其隐藏性格真值。婚后生活可证实、修正或推翻玩家原有印象。

上述场景是为了验收架构的*最小测试夹具*，不要求西汉 MVP 照搬宋唐科举或某时期不适用的婚嫁制度。
