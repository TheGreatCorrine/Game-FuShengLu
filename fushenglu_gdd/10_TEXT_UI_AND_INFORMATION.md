# 10 — 文游主界面、信息可见性与交互（v1.1）

> 产品性质：**文字人生模拟**。UI 是读人生、做选择的载体，不应长成属性养成 RPG 或依赖人物立绘/插画。主要体验必须只靠文字成立。

## 1. 主界面原则

- **先叙事后数值**：一屏最重要的是“你是谁、今年发生了什么、你能做什么”。
- **少量常驻指标**：姓名、年龄、年份/年号、地区、社会身份、健康文字等级、个人荷包、家庭经济概况。
- **不显示**：精确寿命、死亡概率、运气、NPC 真实野心/控制欲、历史事件的全知真相、未得知的家庭秘密。
- **通俗文本优先**：不把“父亲信任 74”放在前端；改为“父亲开始主动问你铺中账目”。可显示部分明确已知的财产数量。
- **可访问性**：纯文字可玩、字体大小、键盘与移动端支持；颜色不承担唯一语义。

## 2. 推荐主屏信息架构（概念文本线框）

```text
┌────────────────────────────────────┐
│ 浮生录 · 唐            天宝十三载  │
│ 沈知微 · 14 岁         江南 · 苏州  │
│ 商户之女 · 未婚                    │
│ 康健：良好  家境：小康  荷包：320文 │
├────────────────────────────────────┤
│ 【春 · 议亲】                      │
│ 母亲说，邻县有人托媒人来问亲……   │
│ 你这些年在铺中已经学会了记账。   │
│                                    │
│ 你打算：                           │
│  ① 听从父母安排，继续商议婚事       │
│  ② 请求推迟，继续帮忙经营           │
│  ③ 向母亲打听对方家中情况           │
├────────────────────────────────────┤
│ 人物志    荷包    家户    年谱       │
└────────────────────────────────────┘
```

- UI 上“健康”用自然语言；不要显示 `health: 76`。
- 小荷包显示**玩家可自由支配**的财物；家户资产另列归谁拥有/管理。
- 选项仅描述角色有合理认知的风险，**不剧透成功率和隐藏数值条件**。
- 平静的年份允许一键推进；重大抉择暂停；不强制每年都弹出戏剧事件。

## 3. 次级页面

### 人物志

按原生家庭、婚姻/姻亲家庭、朋友/师长/同僚与重要往来分组。每张人物卡记录：玩家知道的姓名/年龄、亲属、职业或**官职**（有根据时）、居所、表面性情、共同经历、是否确知及最近一次消息。对于配偶/未婚对象及其父母，可查看**已知**的家庭成员和家计情况；不认识的亲属可以标注“尚未相识”。

区分 `observed`（亲见）、`reported`（他人转述）、`unknown`（未知），婚前媒人说“性子稳重”不能当作系统真相。已死者仍保留在人物志的故人分组。

### 荷包与家户

- **荷包**：玩家可支配的铜钱、货币、物资及其权属。例“320 文”。
- **家户**：家庭总体产业、欠款、收入来源、粮仓/田地/店铺以及实际管理权。少年或已婚角色可能无法处分大部分家产。
- 货币按**具体朝代、时期与区域**指定单位及可得性（如文/贯、绢帛、银或纸币在不同年代条件不同），不能把整个朝代所有年头用同一币制、直接当现代现金余额。
- 当地物价变化可以模糊显示：“近来米价上涨”，仅在角色有可靠交易渠道时才显示精确市价；历史研究与游戏估值分离。

### 年谱

时间顺序记录重要事实、可见事件与自己的旧选择；保留已故亲属及旧关系，但**不提前揭示主角当年不知道的历史事件**。终局单独有“彼时天下 / 命运回响”解锁全景。

## 4. 行动、权限与反馈

玩家选择的是 **attempt/intent（尝试）**，不是 NPC 的反应：

- “请求父亲同意读书”而不是“父亲答应你读书”；
- “试探未婚夫对婚事的想法”而不是“让未婚夫喜欢你”；
- “建议家人迁居”而不是“全家立即迁居”。

不同年龄与家庭权力结构有不同可操作范围。若某选项不可行，优先在文本中合理体现“无权决定/缺乏资源”，而不是堆出大量灰色游戏按钮。

当一个 NPC 反对时，反馈应给**可观察线索**，而非泄露隐藏权重：“父亲望着欠账本，最终摇头”，不要显示“债务 -20、控制欲 +40”。

## 5. 0–20 岁选择密度示例

| 阶段 | 体验 | 选择性质 |
|---|---|---|
| 0–5 岁 | 家庭与环境自动塑造 | 通常不提供超出年龄能力的选择 |
| 6–11 岁 | 学习、劳动、兴趣、亲子关系 | 初步请求与尝试 |
| 12–15 岁 | 家族责任、求学、议亲或谋生 | 争取自主空间、协商 |
| 16–20 岁 | 家庭经济、职业、婚嫁、迁居 | 更多行动权，但仍受制度/人物意志限制 |

以上是叙事节奏参考，**不是全朝代统一成年法定年龄或婚龄**。可供选择的事项由对应历史制度与家庭处境决定。

## 6. 性格与官职如何显示

- 身份/职业/官职属于可证实社会事实；角色知道时显示，如“县吏”“正准备考试”；官职需有 `startYear`, `endYear`, `officeId`, ruleset 校验。
- 外在性格使用逐渐修正的印象：“沉默寡言”“善于交际”“做事谨慎”，可以通过长期相处从“听闻”变成“亲见”。
- “真正想靠婚姻攀附”“不愿承担家庭开销”等隐藏目标不直接在人物卡显示；可通过事件逐步发现。

## 7. 0–20 岁游戏体验验收

1. 玩家能无需查看数字表就知道主要困境以及可采取的行动。
2. 未婚对象结婚后仍是**同一个人**，其年龄/职业/官职/目标/与玩家的关系连贯。
3. 婚配导致新的重要家庭人物可以逐渐认识，而非婚后一瞬间全知所有姻亲资料。
4. 荷包金额与家产明确分离；货币符合该时期，不能凭空把家产当个人现金。
5. 人物信息有已知/传闻/未知标识，NPC 心理属性与未来事件概率绝不泄露。
6. 即使没有背景图和头像，文本仍能清楚传递人物性格、关系变化与历史氛围。

## 8. v1.2 UI 决议（覆盖较旧的线框示意）

- 姓名**只能在出生确认前**编辑名，姓由家族决定；确认后不再出现改名入口。
- 一套统一 UI；地区主题只切换 CSS 配色和极淡背景纹样，不切换布局；避免旧纸泛黄和翻书式阅读。
- 主界面采用「世界见闻逐条出现 + 人生纪事 + 重大选择展开」三层文本流，而不是把所有信息塞入父母对话或单张叙事卡。
- 世界消息通过角色已知渠道展示，人物卡与荷包等位于独立页面；重大剧情可以展开，但不默认生成长篇小说。
- 结局历史人物、事件、成语收集暂不要求 CG，后期可选插画；不存完整人生。细节见 `11_REGIONAL_THEMES_AND_NO_AI_NARRATIVE.md`。

## v1.3 年度行动与人物志表现

- 成年年度主动行动额度通常为 **2**，界面应明确显示剩余额度；童年显示实际可自行提出/执行的行动，不使用统一成年权限。突发事件回答通常不扣行动额度。
- 「市集」作为未来交互入口，同一年最多访问一次，单次可选多件商品后确认；不要把打开或浏览商品界面本身算作已购买或已消耗行动。货币、地域商品及交易限制由历史规则决定。
- 人物志在玩家有足够可观察信息时显示模糊关系状态（例如「亲近」「疏远」「彼此不睦」），同时允许「尚不清楚」；不得露出精确关系值或对方隐藏愿望。
- 主屏只显示玩家眼下需要的资源与处境概况（健康、家境、可支配荷包），细分家庭现金/债务/个人契债仅放详情并在相关重大事件中按需突出。
- 隐藏悟性、勤勉、韧性、通情和专长禀赋通过事件与人物观察间接体现，玩家无法通过菜单直接读取“智商”“情商”数值。
