# Phase 2B.2-B · 婚礼用度、家人意愿与婚后安家

以 Stage A 提交 `dd8d211728e9bb6051c29628d96b78b994b8e02d` 为对照。首次介绍沿用原来的年龄和事件入口。婚议约期、双方同意、仪式付款和正式成家各有自己的时间。双方明确同意后，过了原介绍年龄仍能继续筹办。

## 玩家能做什么

- 回应当年的介绍或对方来信后，可以付六钱行常礼，也可以先议安家。钱不足时保留同一候选人、原回话和双方同意的年份。约下一年再谈不会提前迁居、结婚或取得继承权。
- 从简用两钱。对方可以坚持常礼，重复请求不会重新抽取偏好。钱不足且对方接受简礼时，可问同住家人是否愿意补足差额。每年可问一次，只从同意者可支配的私蓄扣款，不动玩家私囊。家人可以拒绝。
- 可以提出婚后留居本户，第一年陪护一位具名的在户父母。候选人及在户并有决策权的 NPC 都有发言权。提议获准才改变通常的安家方式。翌年复核亲人、配偶和居处，履约留下当事人的记忆。若境况已变则记录未能成行。
- 等待满两年后，对方可能因自家需要而退出。双方死亡和玩家亲自退约各有结案原因。缺钱本身不会退约；等待增加了经历其他变故的时间。

**供后续入口复用。** 介绍来源可在将来绑定合资格的候选人，再调用 `schedule` 约回话或调用 `acceptMarriage` 表达意愿。已有约期必须先等答复。后续入口可复用 `arrangeCare`、`postponeWedding`、`celebrate` 和 `endAgreement`。这些操作读取现有候选人和账户。正式公开给玩家的命令应沿用现有命令边界，复制状态、记录当事人及决定，再交给年调度。既有居民成为候选人还需要单独设计身份绑定；目前候选人在成婚前是户外人员。

## 守恒与复现

三组分别逐次核查 2,284、2,950、2,927 个婚议决定，共 8,161 个。未办礼时每户现金、资产、债务、每个人的私款和借贷记录一致。办礼时逐户验算原付款户现金减少额，逐人验算具名赠与者私款减少额，两者之和须为二或六钱。新登记的姻亲家庭和新出现的姻亲长辈以零财产入账。每笔付款只对应一段主角与原候选人 ID 的婚姻。终局运行身份校验并检查每段婚约已结案。以上是婚议操作的逐笔审计；日常生产、消耗与遗产仍由原系统结算。

## 静态审查结论与非阻塞事项

功能审查通过。审查版本为 d2d5e05，对照 dd8d211。上文 78 项测试、构建、三组同种子结果和 8,161 次决定审计均为先前验证记录。本次新增的是下面的债务分解，没有重新执行测试套件。

**终局债务。** 对“先见面再答应”策略另做一次本地只读诊断。沿用 scripts/marriage-affordability.mjs 的行动次序，分别推进两个版本的 marriage-audit-0 至 999 到死亡。返回每局末尾的 households[id].debt，按（种子、家户账本 ID）配对，缺失的一侧计零。终局开放账本也包含无人居住但财物或欠款尚未清完的账户。账本 ID 相同不保证住户相同。

| 终局账本口径 | B 减 A 的债务 |
|---|---:|
| 两边均有的账本 | +6,123 |
| 仅 B 保留的 171 本 | +19,505 |
| 仅 A 保留的 13 本 | −87 |
| 合计，143,212 减 117,671 | **+25,541** |

以同一批种子按人口结果重新分组，180 局主角婚姻次数不同，贡献 +18,149；21 局婚姻次数相同、子女人数不同，贡献 −340；799 局两项计数均相同，贡献 +7,732。两种分解分别加总至 +25,541，彼此重叠。只在 B 终局出现的账本可能是期间新设，也可能是原有账本关闭时间不同。这些数字刻画差额集中在哪里，不能把各项视为独立因果效应。

原有逐笔审计排除了被覆盖的婚议决定直接增加账本债务。年度经济结算按住户人口、劳动能力、生产资产、费用和旧债计算结余；无人户会保留未清财产与债务。Stage B 同时取消婚配赠产。仍待跟踪两边共有账本从哪一年开始分化：逐种子对齐开闭户、居住人年、收入、消费、资产处置与遗产清偿，并按付款方和账本所有者复核首个异常余额。目前没有证据要求调整婚率，也不能据婚礼守恒断定年度记账已全面排错。

**简礼被拒后的重试。** 对方首次决定后，结果留在这段婚约的 simpleTerms 中。拒绝后，改余额、等下一年或重进菜单都不会重抽；直接再次请求也不能绕过。婚约仍有效，可以等常礼或退约。家人当年拒绝补差属于另一人的另一个决定，次年可以再问。

**照护期限。** 留居条款指定本户一位亲人。婚礼后下一年度检查双方的婚姻关系、存活及亲人居处，记录一次履行或未能履行。已有结果即结束检查。当前实现不逐年安排照护工时、分担费用或持续衡量照护质量。
