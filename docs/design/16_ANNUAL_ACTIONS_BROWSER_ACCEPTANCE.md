# 年度行动 A · 浏览器验收

受测提交 `97eeb843b6cb3234d1589487068d8565d7112a74`。本地 Chromium 133.0.6943.0，无头模式，1280 × 720 CSS 像素；Playwright 操作本地 Vite 开发页面。仅用开发者入口指定种子，随后收起调试区，在正常页面取名“宁”。观察年份、按钮、行动回执和人生纪事。四条单击路径通过，双击发现一项交互缺陷。本次未重跑既有 86 项测试、完整生命模拟或构建；原报告及 1,000 人跳过行动基线原样保留。

复现上述路径时，普通事件选第一项；新对象先见一面，回话时答应。婚约协商依次优先尝试简礼、家人补足、常礼、延期。年度行动按托家人引见、赴现有面谈、问工的顺序选择，每类取第一个可用按钮。没有可选行动时结束，再点“过一年”。

**结束与快进。** “结束本年行动”关闭菜单并保留当前年龄，随后由玩家选“过一年”或“行至下一次抉择”。另开种子 0，从 18 岁直接按“略过主动行动，行至下次事件”，实际停在 24 岁婚议。正常问工、赴约、回话均未自行推进年份。

**可复现缺陷：双击会选中下一行动。** 种子 0，18 岁，选随郑安问布匹，在“确定前往”中心快速双击。结果只有一条邀约，仍是 18 岁，剩一次；但页面已进入“去本地集市面谈”的确认页。单击对照会正常返回选择列表。此时再按确定就会花掉第二次行动。单独双击当年最后一次赴约确认，受测视口下仍停在 18 岁。建议验收修复时保留命令去重，并验证第二次指针点击不能落到刚替换的控件上。

**反馈可见性。** 最后一次赴约后，顶部直接切回推进按钮，回执保留在人生纪事中。邀约到期和中断也可在纪事读到。上述结论限于受测桌面视口及 Chromium；移动端触屏与其他浏览器未测。
