# 家计设计表 · 待审
按当前居住户每年判断；出生身份只给初始资产、书籍与行业机会。五档是可逆叙事描述，无须存储新属性。保留个人工资、具名契债、旧户与现户账本。
 
|处境|生计、收支与资产|劳力与家口|读书、成婚|欠账与恢复|玩家能看见的后果|
|---|---|---|---|---|---|
|困顿|租作或零工，必需支出持续超过产出，已无可售工具|病者或幼儿多，健劳少|须有人代工、资助或从简|易反复借粮；劳力恢复才可能翻身|病后家人接工，停课|
|吃紧|耕织兼作，平年略有余，歉年转亏|一人停工就缺口粮|半日读书，婚议分期|动用积蓄或短借；丰年偿还|商量要留几日帮工|
|温饱|薄田或稳定手艺，平年可覆盖用度|劳力能轮替|能供一人短期学习或办简礼|偶有欠账，有机会在正常生产中还清|收成后兑现承诺|
|宽裕|货担、熟练手艺或管田，有工具和余钱|可承担照料、替工|可连续学习，也可负担搬家|冲击先耗积蓄；可复工恢复|延请教字者|
|富足|稳定盈余及多项生产资产|有余力帮亲属|资助学习、置办新户仍有取舍|经营失败或持续照料仍会下滑|后辈选择守业或另谋生计|

建议先修生产周期。以无灾、收成系数1、父母耕作且两孩的佃户为例，产出16、四口基本消费24，健康年份已经亏8。自耕户两项资产多产3、维护1，仍亏6。卖一项得15只能暂缓亏损。灾年价高、病中停工和医疗支出、60岁亲属统一休养进一步放大差异。建议先按年龄区分消费份额，少年可做轻活，健康老人可择轻活；将实作用于成年劳动效率。分项做配对实验，避免把每户收入同比放大。个人工钱取自本户产出，家户还账不能清掉个人契债。分家换户不能记作旧户脱贫。
