# 出生家户与社会分层 · 西汉切片设计审阅稿

## 旧模型审计

当前 generate 从地区权重抽取 home，再生成父、母、一名较年长手足。姓名、年龄、性格、钱和健康有种子差异；成员结构固定。亲属 kin 默认共用家业，吏家的父亲取得「地方小吏」头衔。家户基本现金另加 0–19，下面的资产是结算用数量。表中书籍是机会系数。

|旧编号|家业|基本现金 / 资产 / 书籍|实际差异与合并错误|
|---|---|---|---|
|0 自耕|耕作|55 / 2 / 1|可读简、有资产可管田；全家是否真的有人教授另无资格检查|
|1 佃作|耕作|20 / 0 / 0|幼时缺直接读简入口；与自耕共享大量家务和十五岁抉择|
|2 行商|贩运|90 / 1 / 2|贸易事件和初业有专门入口；经营规模、路线和同行关系未拆开|
|3 吏员|文书|78 / 1 / 3|十五岁起习艺；病愈返回职业时除商户外一律田间劳作，连吏家也可能被转去种田|

代码核对点：src/data.ts 的 homes 与 scenes，src/engine.ts 的 generate、support、eligible，engine/family.ts 的 kin、joinFamily，engine/livelihood.ts 的复工和晋级，engine/economy.ts 的 yearImpact。后者先按地区算冲击，再按旧编号分消息；新闻不同本身不能证明责任不同。婚后姻亲户的开局现金仍从配偶背景查表。替换生成器时须覆盖这第二个入口。

## 九个体系与开放原型目录

分类无高低次序，同一户可有多项。下表“首轮”表示可在审定后用已有普通家户机制表示；具体出现频率均无史实宣称。每一行可继续添加数据条目。

|体系|武帝期映射及候选原型|首轮边界|
|---|---|---|
|皇族宗室|宗室远亲、诸侯王家属、公主；血缘与正式封号分别核验|稀有身份暂缓，远亲不得继承王权|
|封爵贵族|列侯在爵之家、失侯之后、旁支家属|需核封爵、继承及失爵年代，暂缓|
|官宦|地方小吏、失职归家、县级官员家、郡级属吏家、朝官之家|首轮只保留小吏；其余须核职掌与任职地点|
|地方豪族|田产较多且有乡里联系、受邻里请托、有产而地方关系衰退|先做具名联系的受控家户；地方影响不推定世袭权力|
|士人|有读写传统者、授徒者、家藏简书但失师者|先作识字或师承标签；专门经学与入仕途径另审|
|商贾|肩挑零贩、坐市、往来两地、合伙贩运、货多周转困难、停业清账|首轮以货担、从业者与同行关系区分；官府供货须另有关系凭据|
|农耕|受雇农工、佃作、小自耕、有余粮之家、失田后租作|先用自耕与佃作；经营变动可改变生计，出身保留|
|工匠技艺|家庭纺织、受雇手艺人、有徒工的作坊、金属加工|先用现有织作与具名教习者；官营作坊隶属另审|
|依附与受制|依赖他户供食或用工、具有特定法律身份的人|经济依赖与人身法权分别核实；身份继承、强迫分离等严重情境暂缓|

后世科举家庭、特定朝代的皇商或宫廷选拔只在相应规则包有考据时登记。公主须核家系及名号；富商有官府客户须有实际往来，不能据规模授予身份。被胁迫是带行为人和后果的遭遇，不列作职业晋升或开局收集奖励。

## 最小数据契约及迁移

|数据归属|最少保存|如何读取和更新|
|---|---|---|
|时期规则|规则 ID、有效年代和地区、身份/职/爵目录、出处、准入条件|读取合法行动、授官、婚居、财产和义务；未登记路径默认关闭|
|原型静态数据|稳定 ID、适用规则、可重叠体系、家业候选、资产与亲属配置、可建关系|生成一次；扩容加一条记录和相应时期规则。原型不拥有年结算方法|
|出生事实|生成器版本、原型 ID、出生户、父母或监护人 ID、谱系依据|作为年谱起点；分家、失官和改业后仍可查|
|人物与当前户|本人法律身份、实际所任职官及任期、爵位及有效期；成员、居所、职业、师友/交易关系、人物目标与经历|复用现有 NPC、住户账户和事件记忆；家庭文化从照料者目标及承诺读取，可彼此冲突|
|派生处境|净流动资金、可用生产资产、实际可联络的人、教习时间|资金从现户账户取；关系按有无仍有效的联系人判断。首轮不用综合阶层分；如调试显示商业规模百分位，必须注明同地区时期的比较群体，不作授衔条件|

示例原型 han.itinerant-trader 选择「贸易」家业和可携货物，允许单人往来或与在地伙伴合营。另一个原型可以沿用同一结算，只替换资产和联系人。职官与爵位分别挂在持有人；一人离任不应令兄妹的识字技能消失。

生成依赖：时期和地区筛可用制度 → 合法身份和谱系约束候选原型 → 抽家业、财物、当前困境 → 配置有来历的监护者、同住成员及亲友 → 为每人抽目标和性情 → 从实际人、物、时间导出童年机会。人物禀赋使用独立种子键，不读家境。首轮容许无手足、多手足、父母分业或亲属代养；未成年须有能解释照料来源的关系。亲属亡故应保留身份引用，移除其亲授入口。

迁移顺序：以生成器版本固定旧种子回放，旧 0/1/2/3 映射为稳定原型 ID；旧档仅从已有数据投影事实，不补造爵位、导师或承诺。新生儿和新姻亲户共用原型解析。随后依次替换读书、贸易、病愈复工、婚居和历史接触中的编号判断。个人契债、家户账和家庭资产沿用原结算。先用测试夹具验证多体系，再开放新游戏权重。

## 玩家能经历的分歧

|家庭场景|童年责任和具体机会|少年选择与冲突|成年后可追踪的后果|
|---|---|---|---|
|佃户女儿、家中临时缺人|照看幼弟；邻人愿教她认量器|与监护人商量半日帮工；若无人接替便可能错过|学会量谷可接计量差事；照护记忆影响家人日后愿否作保|
|殷实商户的女儿|跟具名同行点货；长辈患病时改在家照料|随队学算或留下；出资须由能支配货本者同意|同行仍来往才有异地入行机会；断路可能积货、迁居或欠债|
|小吏的女儿|家中可借简；有识字者肯教才开放临写|家人可能期待理账、织作或照料；各自须有实际工具或教习者|学成可替人理账；父亲的任职不授予她官职|
|有地方联系的家户之子|随长辈接待前来求助的邻人，认识特定家庭|出面调解、拜师或回家守产要占用可用时间|兑现承诺可留下婚议介绍人；失信或家道中落会改变资助和搬迁条件|

同类反例：两家货本相同，一家的母亲愿意教算，另一家的母亲要照料病亲。即使两个孩子悟性相同，只有前者当年有课；后者次年可以主动寻师。反向测试为相同机会、不同悟性或勤勉，允许学习速度不同；通情影响察觉难处，韧性影响失败后再尝试，少数专长须接触相应活动才可观察。高音乐禀赋、没有乐器和教习者的孩子不会凭空获得演奏技能。所有原始分数隐藏。

成年每年两个主动行动；找人引荐占一次，回应家人既发的婚议通常不占。同年逛市集至多一次，离开未确认不扣；家庭支配权决定可用的钱。儿童须考虑年龄、监护许可与替工。行动不影响亲属自己改业或拒绝。历史冲击先落到同地区的人和资产：借既有征运场景，佃户可能缺劳力、贩运户可能误期、正在办文书的人可能加班。拟议后果须分别给出接触途径及史料，不能对某出身全员强制触发。

## 配对验证

固定出生年、地区、健康、禀赋、随机键与策略；在生成前注入具名家户夹具，使父母、资产、关系与出身一致。使用 origin-000 至 origin-099，首选、重教育、保守和有效选项随机四策略；切换出身不改变其他随机通道。以下为待实现的验收协议。

|对照|唯一干预及应查的结果|
|---|---|
|跨体系|替换完整家户夹具，其余外部条件固定。比较上述四户 8 岁可用活动、15 岁行动、25 岁入业、40 岁后果；每次差异须能指回一名参与者或一项资源|
|同体系|商户内分别单改货本、导师可用性、监护人期望；比较账本、能否出行和学算资格。只改开场描述时结果应逐年相同|
|禀赋与机会|高/普通悟性 × 有/无老师四格，固定求学选择；有才且无机会不能自动学成，普通资质在持续受教时能进步|
|制度边界|高影响、高财富但无任命者不得有官职；西汉配置不加载科举、后世选秀。无正确亲缘或名号事实不能生成公主|
|升降与身份|同一户分别模拟断路与恢复交易，跟踪钱、债与可接订单。离任须清当前职务而保留旧友；分家不能改写出生户或转移个人债权|
|性别交叉|佃作、小吏两户各生成女、男；对比真实照料负担、识字、入业、议婚时谁有权出资。不得以性别自动给女孩刺绣技能或给男孩官职|

每次记录候选事件、被拒理由、选择、费用、技能变化、义务、具名关系、首次婚议、职业与冲击渠道；保留未发生与被拒案例。各年龄分别报告存活人数，机会率以当时符合资格者为分母。验收提供同种子的两份简短年谱和可重跑的状态差异，单列同户恢复与迁居；不得把试玩配比写成历史人口比例。
