# 下一阶段提案 · 成年主动行动、集市与人生机会

状态：待设计审查。基线为 Phase 2B.2-B 的 d2d5e05。本文提出命令和验收条件，尚无可运行的新功能。

## 一年里的两次选择

玩家每个成年年份最多主动做两件事。两次行动依次决定，第一次的结果可以改变第二次的选项。一次花费代表主动付出的时间和人情，即使对方婉拒也有意义。玩家可以留空或直接结束这一年；次数不跨年积攒。建议首片以满 18 岁作为一般主动行动的玩法门槛，婚姻另行沿用原资格。18 岁可以问工，议亲仍须通过 Stage B 的原有年龄、婚姻状态和身份检查。游戏门槛不构成对西汉成年法的断言。

例如，主角先请母亲为自己引见。母亲说今年抽不开身；这次拜托已经发生，还剩一次行动。玩家可以去集市找短工，不能反复点击让母亲重抽答复。若母亲应允，玩家也只得到一条引见线索。见面、对方回话、双方愿意、实际付款仍各有时间和条件。第二次行动也可以留给工作，明年照常收到对方的回信。

## 年度顺序和消耗规则

1. 沿用年调度先处理年龄、死亡、家计和到期事项。如果有人去世，先使相关约定失效。完成当年原有的待决事件后，才开放主动行动。年度工资、消耗与债务最多结算一次。
2. 阅读已知机会、查看价格、选择对象、取消草稿均为免费操作。有效发出请求或赴约时消耗一次。目标已故、资格过期、同一命令重送、试图动用无权支配的账户等情况不消耗行动、不转钱。拒绝、无空缺等真实答复消耗已投入的那次行动。
3. 已有婚议的到期答复、同一场景的商议及翌年照护沿用原有事件入口，不再收一次行动。玩家主动寻找新的机会才计入额度。处理完即时结果后回到当年剩余次数；不递归推进一年。结束本年后不得重新打开当年额度。
4. 玩家端的快进可明确放弃余下主动行动并继续等事件。旧回放采用“跳过主动行动”的兼容策略；旧状态缺年度记录时仅在下一个可确认的年度边界初始化，避免读档赠送次数。

## 三种入口，共用机会和结算逻辑

| 入口 | 谁决定、有什么约束 | 玩家得到什么 |
|---|---|---|
| 拜托家人或熟人引见 | 选一位角色认识、健在且能联系的具名亲友。受托者决定是否帮忙，候选人独立答复。已有候选人、约期或婚约时回到原事项 | 介绍、婉拒或以后再来。保存来源、参与人 ID、可知理由和期限 |
| 集市问工 | 只有角色能到达且听说有工可问的市场才出现。具名雇主可因无空缺或不合适而拒绝；家中照护与时段冲突时可放弃或另约 | 有期限的工作邀约。报价列明工期、付款者及收款者。接受邀约可占第二次行动，已用完则依到期日决定是否还能赴约 |
| 工作、习读或社会往来产生的线索 | 用既有同事、师友或亲属关系。双方可拒绝后续接触。与已登记人物交往必须复用身份 | 可转为进一步学习、工作或引见。一次成功交谈不会直接生成职业、配偶或存款 |

集市在首片只提供“去问工”这一种服务；后续媒人可调用与亲友相同的引见操作，单独声明服务费和退款规则。暂不建设商店、库存、婚恋介绍所或商品经济。将来开放媒人时，付费只能购买服务，不能购买他人的同意。

## 谁能做决定，钱从哪里来

个人拜访由本人发起；承诺家户资金、共同劳力或留居，要取得实际有权者的意见。户主、受托者、候选人、雇主可以是不同的人。拒绝保留其本人、年份和具体事项；同一事项重复询问不会刷新偏好。新条件有实质变化时才允许提出新事项，Stage B 已存的简礼拒绝继续有效。贫富、训练、住所和关系影响能得知哪些机会，也影响能否履约。角色只看到自己听到的答复、认识的人和可观察的费用。

首个付薪机会仅限存在可识别付款账户的雇主。成交前明确收入归私囊还是家户；履约时从付款方扣款，一次性记入授权的收款方。工资若已覆盖在当年生产中，先分清替代工时与新增工作的口径。首片可只发出面谈邀约，付薪与工时账未核清前不开放领钱。

## 建议的领域接口

- 查询可用行动是只读操作。提交通用行动时重查年度、余次、目标、关系、已有约定、可用工时和账户权限。每次提交带唯一命令标识；保存状态、次数和结果在同一次命令处理中完成。重送同一标识返回同一结果。
- 机会独立保存来源人、目标人、开放与到期年、条件、决定和可观察消息。年度额度归主角；是否愿意帮忙归 NPC；产权归现有账本。三类状态各有一个权威记录。
- 引见先绑定唯一候选人，再复用现有 schedule / acceptMarriage / arrangeCare / postponeWedding / celebrate / endAgreement。随机引见、主动引见和未来媒人进入同一条婚议。现有 bindCandidate 创建户外候选人；在支持把居民绑定为候选人之前，居民仅作介绍人，不复制一名居民当配偶。
- 机会生成与 NPC 决定使用独立的确定性随机键，由种子、年份、事项和稳定人物标识构成。显示菜单、读档或重送不能改变结果。保留原命令的复制状态、记账和玩家观察边界。

## 首个可审查版本

只用现有选择列表呈现两种主动选项：“托一位家人引见”和“到集市问一份短工”。第一条走到原婚议回话，第二条走到具名雇主给出或拒绝面谈。这样可以试玩两个愿望竞争同一年时间的情形，同时检查家人、对象和雇主能否分别作决定。通过后再单独评审从熟人中选择对象、媒人收费、工资结算和更多工作或习读机会。

**未来本地验收。** 覆盖零次、一次、两次、第三次被拒、跨年、快进、死亡、失去联系人、机会到期和重送。测试拒绝消耗一次、无效请求零次、到期回话零次；验证一笔承诺不能重复成婚、收钱或改变账户所有者。用同一批 1,000 个种子对比“全跳过”“优先引见”“优先问工”三种策略；全跳过应复现 B 原策略的逐局关键事件。按出身、居处和负债状态报告可用行动、拒绝原因、完成机会和每次花费，检查贫困玩家是否实际有可作的决定。下一审查点决定问工是否值得花一次行动，以及家庭限制是否给出了可理解、可回应的理由。
