# Phase 2B.2 设计审查稿 · 婚事、家人意愿与人生走向

**建议先做「婚议有回音」和「办不起也能谈」，婚龄另作对照实验。** 当前玩家遇到的问题，是明明愿意成家却始终收不到后话，以及家里缺钱被写成对方不愿意。提高所有人的成婚概率，会掩盖这两处原因。

Phase 2B.1 已在 `d7a51cf964cd77162dec0c1166b4c1ce14d3c2e4` 验收收尾。其 4–6 岁有 56.9% 空年、长期影响集中在十五岁、四十岁职业分歧有限，已记录为后续玩法考量。本提案只附读取该版本的诊断脚本。下述路线、观察指标和参数都是待审设计。

## 实测漏斗

以经审提交的源码从出生跑到死亡。每种策略使用相同的 1,000 个种子（marriage-audit-0…999），共 4,000 局。其他事件一律选首项，仅改变婚议回复；随机策略在三个可见回复中等概率取一个。每局终点检查人物、关系与家户不变量。分母按问题区分：是否遇见看人，机会频率看合格人年，失败原因看主动求婚次数。下表“议亲场次”包含同一候选人后续回话。

- **资格与机会。** 初婚窗口为游戏年龄 20–34 岁，丧偶后最晚 52 岁，另有等待期。合格年份进入普通事件池，每年先过 29% 通用暂停判定，再以权重 3 与其他事件竞争。总是答应时，每个合格人年出现婚议的频率为 7.7%。941 个曾合格者中，有 299 人一生都没收到婚议；首次收到者的年龄四分位数为 22、25、29。首婚年龄仅对实际成婚者有定义。
- **拒绝与延期。** 当前只有同意、商量、暂缓，没有永久婉拒该人的操作。总是答应的 846 次尝试中，61.2% 被六钱现金门槛挡住，另有 11.9% 资金充足但未谈成；只看资金充足的 328 次，未谈成比例为 30.8%。现有台词将两种失败都解释成对方的打算，无法从旧轨迹识别一个真正独立的「对方拒绝率」。
- **先了解对方的代价。** 会面在后续同意判定中带来 0.09 加成，但所有回复都要等三年，再参与普通抽选。654 位谈过的候选人中，239 位再次获得回话机会（36.5%）。其余可能受到年龄窗口、死亡或事件抽选影响，不能一律算主动拒绝。相比总是答应，先商量使初婚人数从 221 降到 95。
- **财务所有权。** 同意先从当前家户支付六钱，未计玩家荷包。原户账本仍属原户；另有明确的婚配配置按候选人出身分配现金和资产。首次婚配可触发迁居。总是答应的 221 次初婚中，129 次迁居（58.4%），婚前原户有债的成功案例为 0。这是该批轨迹的观察；代码中的债务影响成功加成，现金才是硬门槛。

### 成家如何改变后半生

总是答应时，221 名初婚者中有 173 人有亲生子女，共 286 名子女（含先于主角死亡者）。28 岁前初婚的 137 人中有 116 人有子女，28 岁及以后初婚的 84 人中有 57 人有子女。先商量策略则有 61 名父母、89 名子女。年龄、家境、健康和存活时长共同影响以上分布。当前规则要求配偶在世、双方无急症且健康值均至少为 40，双方较年长者至多 41 岁；间隔至少三年，有家债时生育抽选系数为 0.65。诊断复核时应注意：正常成婚会让伴侣同住，但家族发展函数本身选取在世配偶，并未单独检查两人户籍相同；未来若引入婚后分居，须先定义此处规则。死亡后清算仍要按实际亲子关系和既往婚史处理。

## 历史依据及适用边界

《汉书·惠帝纪》记惠帝六年（前189年）有针对十五至三十岁未嫁女子的税令。这能支撑早期汉廷干预婚龄、家庭可能面对外部压力，却不能直接给出武帝时期各地的初婚年龄分布、实收税额、男性年龄曲线或婚姻自主程度。古代记岁与引擎生日后的年龄也有差异。建议把时代压力写进家人各自的考虑，保留不同选择而不普遍扣钱。[《汉书·惠帝纪》原文及注](https://www.chineseclassic.com/content/1449)

秦汉之际家户与出土律令研究显示，婚后居住和入夫方／妻方家庭会带来具体的家户地位差异。时期与身份必须标明，墓牍与法规也不能直接估计普通人某种婚居的比例。这支持把婚后住哪里、谁需要照护放到婚议中谈；当前六钱、固定三年和下述测试窗口均为游戏参数。[Qin–Han transition household study](https://doi.org/10.1163/24689246-20250015)

## 可审方案

| 方案 | 玩家实际做什么 | 待测试的设置与取舍 |
| --- | --- | --- |
| A · 婚议有回音，优先 | 初次介绍后可答应、相见、约期或婉拒此人。相见时谈一件具体事，如婚后照料哪一户。议定下次回话的年份，由同一候选人兑现 | 首轮保留 20–34 初婚窗口和首次介绍率。对照次年／两年后回话。双方仍有资格时进入待办；病亡、迁离或主动撤回给出可见的终止原因。同年重大事件优先，回话可延期一次。婉拒只结束本次婚议；普通暂缓不自动承诺结婚。可提升商量的价值，但首次机会缺失仍在。 |
| B · 两户能不能过下去，建议和 A 分批试 | 候选人提出自己的居住或照护意愿；本户有实际户主时才有具名意见。玩家可请求从简、推迟筹措、询问亲人能否出资或拒绝。即使双方愿意也可能暂时办不到 | 用同种子比较现有六钱与议定的简办方案（例如二钱）。只有双方接受、实际付款方可承担时才成婚。亲人的私蓄须本人同意，债务和财产继续归原所有者；不默认举债、无成本置产或重复领取婚配配置。门槛降低也可能让配置成为获利手段，须核对每一户的净变动。 |
| C · 调整首次机会与年龄，独立试验 | 家人或熟识的介绍人有理由时来提婚事；无同住长辈时仍可由已有关系介绍。长时间等不到合适人选本身也是可能的人生 | A/B 后再分别比较「保持 20 岁入口，只提高连续未获介绍者的机会」和「18–19 岁可听到初次介绍，仍由双方答复」。先单独改一个因素。18 岁是测试窗口；现有材料不足以支持给男女或每个出身套一套固定早婚率。提前介绍可能挤掉少年成长内容。 |

**建议审查顺序是 A → B，再决定 C。** 例：一位佃户子女愿意成婚，母亲仍需要家中帮手，候选人也有父亲要照料。玩家先商量能否就近生活，来年同一人回话。如果两户同意但钱仍不足，年谱记录实际障碍并保留从简或延期的余地。另一位家人可以支持也可以反对；主角十五岁与谁有过共同经历，可影响谁愿意代为说话，不能代替候选人同意。候选人未入户前不结算劳动或消费。幼年场景、界面样式和通用经济规则均沿用验收版本。

## 若获批后的验收建议

1. 冻结本表和种子，A、B、C 各自独立对照。继续追踪初次介绍年龄、从相识到回话的间隔、首次婚龄分布、终身未婚及原因。按性别、出身、存活与合格人年分层，报告分子分母。
2. A 的试验目标：对约好回话且双方健在、仍符合资格的婚议，至少 80% 在约期或其后一岁内有明确结果。单列失效原因。同时报告全部见面者的后续率，防止通过缩小分母获得改善。始终婉拒的政策应维持零成婚；家人意见和延期都不能被当作本人同意。
3. B 的试验目标：将佃作户中因当下现金不足而无商量余地的求婚比例由 269/286 降到一半以下；另外报告从简后仍未筹足、候选人不愿、家庭照护冲突各占多少。不同出身应产生不同路径；不以婚率相等为目标。
4. 逐户比较婚前婚后、双方亲人五年后住处和负担、第一胎年龄、子女数、旧家支持与后续继承；过早死亡单列。用相同种子示范「先谈／立即答应／坚持婉拒」到四十岁的可见差别。早婚率、成婚率、生育率均不能单独决定方案优劣。
5. 史料不足的地区差异、强制婚配、离婚法制和 NPC 再婚扩展另行研究；武帝时期按地实收未嫁税不在建议切片之内。此次仅提交提案，玩法实现等待审阅。
