# Phase 2B.1 · 西汉童年与成长

## 体验和验收口径

出生由现有初生页交代。1–3 岁从照护者、疾病和本户营生写入年谱，婴儿不作抉择。4–6 岁在一个由种子决定的年份与亲人玩耍或模仿；7–10、11–14 岁各有两个不同的互动窗口。窗口之外仍可发生既有事件。照护者缺席或无人符合条件时允许空年。一次经历不能重复刷取。

在测试前设定以下切片目标。分母取该年龄段实际活过的年份；死亡当年单列排除。出生年只计初生观察。空年是没有新年谱、当地见闻或待选事件的年份；余额波动不算一件可读事件。

| 年龄 | 可见节奏目标 | 抉择 |
| --- | --- | --- |
| 0–3 | 空年低于 10% | 0 次 |
| 4–6 | 空年低于 70% | 完整经历该段者通常至少一次互动 |
| 7–10 | 空年低于 50% | 有学习、往来或家务可选 |
| 11–14 | 空年低于 50% | 能承接旧经历，逐步独自办事 |

四个年龄段分别报告每局事件数、空年和重复场景。不同种子至少产生十种童年新场景序列；成对重放应能找到改变十五岁可选路线和四十岁可见经历的案例。分布目标是玩法判断，用来指出偏稀或偏密的年龄段。

## 人物和长期因果

同一场景在资格判断、叙事与结算时解析同一个同住、健在且能参与的人。每次选择将具名伙伴、当年年龄和学习／动手／交往的经历写入原有决策账。角色记忆和信任分别由既有系统持有。手上工夫累积练习，辨字积累技能，用心往来则使伙伴更愿意相助。旧简需要家庭有读写条件、能腾出资源并有愿意教的成年人。江南苇叶、商家货担、耕户谷穗分别用地区和营生筛选。伙伴离去后旧经历仍在，要求本人参与的后续机会关闭。

同一个人还在身边时，先前辨字可解锁十五岁带旧字求教，家中仍须承担原本的费用，家人仍可能拒绝；做过的活可让主角选择跟熟人接手整件差事。四十岁若走过这两条具名路线之一，年谱会重提十五岁商量的实际结果和当下生计。原有职业和学成判定继续使用技能、练习、健康与家庭条件。

## 史料边界

中央研究院史语所博物馆的居延、敦煌汉简展记录了习字材料、反复使用的简牍和练习文本。中国国家博物馆的秦汉展列有西汉陶仓，提供贮粮生活的物质背景。边塞简牍与随葬器物能支持器物和活动的选择，不能推出全国儿童的识字率、家务分工或统一入学年龄。年龄窗口、家庭对话、游戏、信任变化和成功加成均属叙事与玩法设计。没有把东汉文献中的入学安排套作武帝时期的普遍制度。
