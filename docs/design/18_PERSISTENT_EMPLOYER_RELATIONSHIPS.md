## 玩家怎样认识他

在关中，玩家随同户熟人到集市问「整理布匹」或「照看货担」，得到邀约后实际赴约，才会由该熟人引见布贩张平。光有行商出身、光看菜单、问工被拒或放弃面谈都不会生成联系人。织作与贩运是两条不同的引路途径。先前付出的赴约行动包含这次当面介绍。同一生中，经不同熟人再相识仍是同一个张平。

点开「相识」可免费回顾对话；只显示主角听过的条件和经历。继续问张平这批布的活，用一次行动。搬布请求遭拒后，学会读货单可以回去问核单；也可以等下一批。读单沿用本作学成或技能达到三点的规则。货批以两个游戏年为一期，判定取人生种子、固定商摊键、货批和任务。换按钮或命令号不能再抽一次。答应面谈之后，来年到期提醒免费；到市赴约占一次。主角承诺留家照护的年份不能赴约。所有邀请在赴约、过期或中断时关闭。

## 另一组同种子完整人生 · 布市问工优先

优先履行张平之约或问他本人，其次赴引路人之约、向引路人问工；遇家人需照护优先答应，其余事件取首项。每次主动提交都深比较家庭账本、已关闭户、个人钱财、贷款与遗产结算。可达性以每个存活成人年处理完既有事件、第一次打开行动区时为准。无可达雇主包含尚未相识、失联、健康或照护限制；当年稍后仍可能结识张平。首次引见按人生计，其他行动按次数计。「过期／中断」按发出邀约当时分组，「照护」属于中断。三个分组维度各自独立。

## 复验入口与限制

在本分支运行 npm test 与 npm run build。以 Stage B 的独立 checkout 为参数运行下列命令；浏览器脚本需本地 Vite 开发服务、Python Playwright 与 Chromium，可用 GAME_URL、CHROMIUM_PATH 指定。

```sh
node scripts/annual-action-runs.mjs ../stage-b skip 1000
node scripts/employer-cohort.mjs 1000
python scripts/test-employer-browser.py
python scripts/test-annual-double-click.py
```

《汉书·儿宽传》记有贫困读书人赁作的个案。提案所列马氏研究讨论秦汉雇佣与人口流动。张平、关中布摊、两年货批和受邀概率都是虚构玩法，不能用这组数据推断西汉工价、雇期或普遍择工规则。玩家端只展示亲历的消息。

本片只有布市一个新地点和布匹一种行当。迁走、死亡及引路中断的关闭行为有固定夹具覆盖；游戏尚未为这位商人新增独立迁徙或死亡事件。实际人生可以因家庭变动失去渠道。下一次评审可先看换户以后能否凭已经建立的信任独自重访。若再研究带薪劳动，须先确定付款人和收款户、实际占用的工期、被替代的家庭产出及取消履约规则。现阶段面谈只产生关系与信息。
