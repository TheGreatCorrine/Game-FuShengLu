# 同一批种子的前后对比

quality0 至 quality999，各自从出生运行至死亡。抉择按种子与年龄选项索引抽取，前后版本采用同一策略。某条机会是否出现取决于状态。现金和负债按当龄存活样本计算；死亡统计用全部出生。此实验用于可玩性与回归诊断，不是历史人口估计。

updated.json、baseline.json 包含逐年龄职业计数、家财四分位、负债人数、NPC 职业变动、终局存活亲属数、各事件次数、分地区历史暴露。changed 统计出生时已有的三位亲属中终局责任不同于出生时的人数（含开始工作及休养），不是每年变更次数。婚谈总次数含婉拒和重试。未到历史节点就死亡的角色不产生对应记录。

## 一组可重放的人生

pair6 使用同一个出生快照的生成规则。15 岁分别求学或留家，其余抉择始终选第一项。选择导致机会集合变化，比较的是两条完整路径。学习路线获得 4 点识字、进入核账事件，40 岁代人理账，家中 311 钱；留家路线识字 0，经营货担，家中 93 钱。pair.json 保存实际选择与关联记录。该例经筛选来展示机制，不能推断求学普遍更富。年龄 40 不再触发奖励或回顾事件。

## 架构及参数

engine.ts 负责公共命令、亲属、选择与结算顺序；engine/types、rng、mortality、livelihood、economy 分别保存领域模型、分流随机数、风险函数、谋生转变和地区/财计结算。data.ts 保留原西汉资料与事件。地域冲击改变运输、生活品价格和患病压力，再经家庭生产与消费、次年医药开销传导。诊断参数记录急症、风险和体质。死亡没有固定年龄。婴儿和儿童的风险单独可调，所有默认数值都是游戏设计假设。婚后同户或另居均有可能，另居时原账与新家计分开；本人领取的工钱来自当年收入。

## 验证与限制

11 个 Vitest 测试通过，包括另行跑完 512 局逐步检查、参数边界、婚谈失败后的冷却、同种子分支、生死与资产状态检查。严格类型检查、Vite 构建、独立 HTML 的离线 DOM 取名至结局/重开交互均通过。未复核真实设备的排版。

当前以年为单位，未细分婴儿实际死亡月份。疾病、资产与收益为简化指标。核心亲属均推进，但另居原生家庭只保留财产与部分亲属转入，不独立核算完整年度收支。只支持一段婚姻和一个子女。佐理文书是罕见的地方文书辅助机会，没有官职铨选。没有对不同性别和身份机会进行系统史审。下一阶段优先做跨家庭背景盲测，观察持续负债、急症可读性与成年选择密度；其次补婚后家计与亲属赡养；再扩充有史料支持的制度内容。
