# 西汉债务与继承的证据边界

适用范围是现有西汉自由编户原型，出生窗为前141–138年。史料入口是 Barbieri-Low 与 Yates 的张家山汉简法律文本校译 Law, State, and Society in Early Imperial China（Brill，2015）。作者介绍区分《二年律令》与案例材料《奏谳书》，涉及财产、继承和妇女身份。参考 https://barbierilow.faculty.history.ucsb.edu/?mbt_book=law-state-and-society-in-early-imperial-china-2-vols-a-study-with-critical-edition-and-translation-of-the-legal-texts-from-zhangjiashan-tomb-no-247 。本轮查到的是书目和研究范围，未取得可核对武帝时期具体民间债务责任的适用条文。早汉文本不能直接证明后来各地的执行情况。

以下均为**原型玩法假设**：家计亏空归该户，个人明确借入的款项才归本人；分户不连带。父亲有能力时决定出生户的重要支出，母亲为第一顺位代理人。亲人死亡只处置本人私财和本人契债。现存亲生子女平分净遗产，不分男女；仅以遗产清偿，超额欠款核销。无在世子女的余款归所在户。整钱余数按稳定身份顺序分配。借贷可受私财、已有债务、是否掌产、亲属担保意愿与出借者偏好影响；性别没有独立的法律禁令。实际概率、金额、期限均属玩法参数。

现实中的催索、依法承担的义务、违法强制是不同问题。口头索款不产生契债。后续法制资料需分别核查法令、地方执行与社会实践。《当朝律令》、人口典卖、强迫劳动、掳走和因债解婚均留待后期史审。

授权信贷的性别差异是对个别出借者偏好的假设：只有未掌产、私蓄偏低且出借者要求担保时，担保意愿才会影响这条路径。两个性别都能通过资财或家庭支持获得信贷；此处没有设置女性不能立约的法条。出借者是本地外部账户的简化标识，不属于已生成亲属。当前不计利息，不作代位继承或继承放弃选择。

家计简化补遗：无人旧户用本户现金抵同户欠账。余财或余债继续记在原户名下并休眠，只有完全清结才封户。这是归属不明时的保守玩法处理。父母双亡本身不触发分户、销债或丧失子女身份。依家庭角色接替掌家亦属玩法简化。
