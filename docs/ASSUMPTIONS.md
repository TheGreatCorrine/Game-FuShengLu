# 西汉内容边界

出生窗为公元前 141–138 年。关中、河东、江南是宽泛的模拟区域，不代表同级行政区划。所有样本均属自由编户；家计、职业、声望及可读书条件分别建模，未覆盖奴婢等其他法律身份。角色可活过武帝在位窗口；后续年份继续模拟家计和亲属，但无后续政令内容。没有把后世科举移植到汉代。

史实节点为前 121 年霍去病出击河西、前 119 年漠北之战。核查入口为《史记》卷一一一与《汉书》卷五五。现代纪年交叉参照 [The Han–Xiongnu War chronology](https://api.pageplace.de/preview/DT0400.9781526790699_A49460128/preview-9781526790699_A49460128.pdf)。所列两场军事行动不随角色选择改变。粮价、运费和健康的数值及先后强弱均为测试假设，不能作为具体郡县发生过同等征发的证据。地方短讯与家庭成员均为虚构。

出生地区等概率。按自耕、佃作、商贾、吏家排序，关中家庭抽样权重为 5/3/2/2，河东为 5/4/3/1，江南为 4/5/2/1。寿命、婚配年龄、识字与性别机会修正、继承份额、钱数和 NPC 行为均为玩法参数。钱作通用记账单位，未模拟币制更替。主角生于已有一个较年长手足的家庭；未模拟完整人口分布。配偶和子女共享家计，无婚后财产权、跨户义务或姻亲网络。
