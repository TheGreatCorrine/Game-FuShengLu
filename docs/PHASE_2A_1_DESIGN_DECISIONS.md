# Phase 2A.1 · 设计审阅单

## 已有依据

秦汉简牍有妻或寡妇作为户主的案例。家户决策应能容纳这种情况；个案无法确定地区普遍比例。惠帝时未嫁课算的年代和适用范围见婚姻设计表，不能据此设定所有西汉人物的法定年龄或初婚中位数。详见 design/02_LIFE_STAGES_AND_MARRIAGE.md 的研究出处。

沿用已确认的方向：婚议自主权随时代、家人权力和角色处境而变；人物志只给可观察的关系印象。个人契债与户债分别结算。没有可靠人口样本时，不把历史猜测设为目标百分比。

## 建议玩法与待确认项

| 待确认项 | 推荐首轮实验 | 取舍及验收 |
|---|---|---|
| 普通家庭的用度与劳力 | 先单独测试儿童半份基本用度，再单独测试少年帮工；最后组合比较 | 帮工须和求学争时间；应能解释健康平年是否仍亏损，并保留病灾致贫和复工还债 |
| 首次议婚和费用 | 第一轮保留现有成年窗口，先测试见面后次年可回帖、缺现钱可商议简礼 | 能区分等待、无力和明确不愿；可能增加重复婚议，需限制同一候选人反复打扰。年龄前移另审 |
| 能力和健康 | 先测试以实际工作积累实作、恢复后可重返学习 | 会改变职业与学习分布；保持低资质有机会、患病后还能恢复，不提高全员成功率 |
| NPC 线规模 | 2B 先用积谷与传艺两项目标验证有始末的回访 | 范围较小，但能直接验证同一人物的自主行动与记忆 |
 
## 已确认的实现问题

回家帮工和婉拒雇请曾直接增加个人工钱，本次已修。原本简化的外部雇工价格保留供独立校准。账面公平、成婚分布与人生多样性仍须在上述设计确认后进行配对实验。四策略出现的差异不能替代玩家体验验收。
