# Phase 1 verification

TypeScript strict check, Vite production build and all eight Vitest groups passed. Deterministic policy sweep: 512 different seeds, complete lives, every transition inspected. No stalls, repeated single-use choices, out-of-range monetary/health values, dangling decision causes, backwards clocks or child-without-partner-record failures were observed. Tests cover both regional date boundaries and the personal/household split. Paired tests vary household access and living parent disposition, and follow delayed study decisions from age 15 to 40. Frozen NPCs and immutable names are explicitly tested. The sweep uses a seed-dependent policy; it cannot cover all paths or validate historical prevalence.

The built single-file production bundle was evaluated in jsdom with external fetch blocked. Name entry, advance one year, repeated choices and fast-forward, terminal reveal, absence of debug controls and restart passed. Native Chromium startup was prevented by the host socket restriction. Rendering, accessibility and mobile interaction on a real device remain unverified.

Next evaluation: balance income/debt, mortality and quiet-year pacing across larger cohorts; compare age-40 occupational frequencies for matched age-15 branches. Obtain historical review of exposure and family rules before expanding the event pool.
