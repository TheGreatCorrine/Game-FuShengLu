# 验收与重放

1.6 的 家户亏空已按家户独立结算，但亲属遗产仅按固定比例拨给主角，没有登记个人负债或其他子女的权益。此次保留原有家计与健康时序，在完成同年所有死亡判定后才选择在世继承人。每个有亲缘关系的所有人独立清算一次。已转移的私钱不会重新进入遗产。家户的田产、现金和亏空不重复计入个人遗产。本期假设个人债务只能在遗产价值内偿付。清算后写入债权本金、未偿余额、核销和每位继承人的毛额、清偿及实得额。

在 rules.legalRules 配置规则身份、继承资格、清偿额度、分配方法和借贷参数。legal.ts 负责私账、掌家人、负担能力、借款与结算，原有 economy.ts 继续按户结年度收支。个人债务预留款只影响可选的大额置办，日常吃用继续按家户结算。家书自愿代还和债主对别户的口头请求不会确立新责任。纳入原有求学、婚谈、家庭商议、家书，以及市上短借、到期核账、旧户索款、置办工具和遗产清算。一年可无事发生。付不起束脩时仍可求学，父母有意愿和余钱可以补足。本人持有契债也不会导致自动离婚。

## 验证结果

22 项 Vitest 测试通过。另用 debt0…debt511 的首选项策略走完全生，逐步检查负债引用和清算守恒。338 人借过个人短借，出现329次本人借契催还、29次对旧户债务的口头索款、18笔资不抵债遗产。505 人活到5岁。频率只描述这批策略和样本。生产构建与离线 DOM 操作（取名到终章、重开）通过。未在手机实机验收。

docs/debt-runs.json 保存 A 至 D 的种子、选择与状态。A 为 debt3，15岁原户欠70钱、现金为零，此次求学未成。B 为 debt2，39岁拒绝原户欠款3钱的要求，自己仍持61钱，新户无债。C 是受控三继承人案例，私产600、本人债务300，各得净额100；另有单元测试覆盖不足清偿、重复清算与已故子女。D 为同一笔10钱欠款及相同私蓄，改变求助对象的性格、目标与关系后重放，分别同意和拒绝。

外部出借人采用聚合账户；亲属担保意愿表示支持申请，未建立一份由担保人承担风险的契约。仅有私钱作为可继承个人资产，资产交易与遗嘱争议留待后续。首选下一步是盲测：玩家在看账、拒绝索款及领取遗产时，能否自行解释负担由谁承担。
