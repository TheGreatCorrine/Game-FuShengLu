# 家庭连续性验收

运行 npm test、npm run build。15 项测试包括 512 个 batch 种子的逐步状态检查，以及婚姻、离家、出生间隔、照应记忆、病故和急症的同年劳动、两户间的转账。另对独立 HTML 做过禁止网络请求的 DOM 操作，从取名、快进、选择到终章和重开。未在手机实机复核。

## 可重放的六组场景

Node 22.18+ 或 24 下运行 node scripts/families.mjs。family0…511 顺次逐年结算，遇事总选第一项。完整结果在 family-runs.json。单独运行 node scripts/memory-pair.mjs 获取 D 的受控对照。

|场景|种子与观察|
|---|---|
|A 自主谋生|family0 主角45岁时，配偶朱平为补债由耕作转织作。family1 的两位父母在主角幼年先后接织活。是否转业受本户债务、目标、进取倾向和当年机会影响。亲人也会教晚辈识简、手足成婚另立门户。|
|B 成亲入户|family12 在26岁应允婚谈，与许和成家，与两位姻亲长辈共居；配偶的亲缘记录可分别追溯到两人。|
|C 别户家计|family15 在30岁时，已离开的原户由无债变为欠3钱，当年两位成员仍在该户。|
|D 关系记忆|memory12 是明确控制的实验。20岁修屋时照应父亲或去做工。固定五年后的钱、家债、人物和机会，25岁开口求助。照应组从父亲私蓄还清10钱；另一组请求被拒，仍欠10钱。五年间没有模拟其他接触，便于隔离差异。|
|E 家中来信|family15 在37岁选择送余钱。荷包36→25，原户欠款11→0，收款亲属留下此事的记忆。|
|F 丧偶后再婚|family47 在21岁结亲，22岁丧偶，44岁再婚。两任伴侣有各自的身份；前一位保留在亲属记录中，存活配偶为第二位。|

512 局独立诊断中，503 人活到 5 岁，199 人结婚，104 人经历丧偶，5 人再婚，90 人迎来多个孩子，24 局触发原家来信。最大亲属记录数为11（含已故）。这些是固定策略下的样本结果。

## 当前年度顺序与架构

advance 推进日期 → economy.environment 更新历史环境 → 主角及全部已生成亲属结算健康和死亡、遗产与丧偶 → economy.household 按每个家户的在世可劳动成员结收支 → family.developFamily 处理年末转业、教学、成家及添丁 → 延期后果及主角生计 → 选择资格。死亡和急症在当年不计劳动，新出生者和年末职业变动从下一次财计开始影响生产。按年近似，不折算部分劳动。

出生、伴侣原户、手足或夫妻独户均有可追溯的成员和账本。活跃家庭沿用原现金接口，别户持有独立账目。家庭互动记录人物、年份和信任变化；最多保留八条重要回忆。普通亲友只在需要时实例化；姻亲每年健康与结算照常，额外自主行为低频。家中商量使用掌家成员或可提供资助的成人。全部规则离线执行。
