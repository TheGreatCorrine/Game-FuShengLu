# 从一个具体的人开始写

选择暂停时，先从当前状态绑定发起人，再使用同一绑定生成正文、筛选选项和结算。参与者资格同时检查生死、户籍、身份与当前需求。普通玩家只读看得见的事实和当事人的说法。关键抉择保留停顿；不会每年轮流让所有人说话。

|事件及发起人|玩家能知道什么|行动、成本和可能的后续|
|---|---|---|
|求学与家务：十五岁时的掌家亲属；其后正在读书且欠债、以积谷为目标的父母可再次提出用工|邻里能教字，家中明日缺人。喜授业的人先问时间安排，重生计的人先问谁顶工|全日需凑五钱并征得支持；留家得到实际劳作经验；有两钱可尝试半日课，务实的家长仍可能拒绝。习读到十八岁再结业，机遇还取决于健康、家计和能力。|
|手足另过：同住的成年未婚手足已有四钱私蓄，并想攒钱或拓展生计|手足提出拿自己的积蓄另过|个人再出四钱，双方各出四钱设立独户。介绍织活需要对方应允，可留家转业；请求推迟留下记忆。已有的自主成婚机制也能改变这条路。|
|议亲：有媒人或掌家亲人介绍的在世对象|正文点明姓名、出身、生计和对婚后生活的顾虑|回帖要考虑共同用度和双方意愿；先会面会留下记忆，影响下次回帖；单纯缓议不产生钱。再次见面沿用同一人，她或他也会衰老、患病或去世。|
|换生计：在世同户配偶尚未织作，且有进取心或因欠债想攒钱|配偶说明看上的活计和所需线料|主角可拿三钱置线、分担家务让对方试做、或劝阻。进取心强的人可以坚持换活；受资助后的织作进入以后的家庭生产。|
|家人病伤：同户、在世且确有急症，优先状况较差者|具体姓名、称谓和病伤；当事人会表达对花费或陪伴的顾虑|有五钱可请人照看，恢复程度有差异；留下护理改善病人状态并折减下一年度主角产出；尊重静养留下关系记忆。|
|原家求援：已分户、原户有在世成年联系人且确实欠款|写信人的身份、上次照应及本次要求|立即代还按两户实账结算；说明难处留下关系变化；约定来年付款仅在届时仍有人收、确有欠款时结算，按实际私钱履约，失约也会被记住。|

角色长线目标沿用积谷和授业。私蓄充足、无债并有进取心者可以从储粮转向授业；教会第一个孩子后，欠债也会让长辈转回维持家计。目标改变需有实际事件。人物记忆继续使用有上限的记录表。

后续增加事件时，至少提供两项在时间、钱、机会、住处或关系上具有不同结果的策略。先检验权限和可用资源，再落账；NPC 可以回绝。未来作者应为每项延迟结算说明参与人死亡、搬走或债已清时如何处理。金额、婚谈冷却、家长继任和年内照护折算沿用或扩展玩法假设，不据此推断西汉婚俗或医疗疗效。
