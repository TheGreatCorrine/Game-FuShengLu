# 按共同生活的人结算家计

成员以人物当前居所为准。主角住处用 residence，每位亲属用 house；亲缘关系另外保存。沿用当前户的现金、欠账、生产资产三项，其他相关户也只保留这三项。移除了出生户重复引用。私蓄始终留在个人手里，赡养与代还需要明确动作。

每年先处理病故与个人遗产，再结算各户。生产来自有劳动能力的同户成员及家产。未就业、急病、失能或休养者不按成人全工计产。取消单凭出生背景每年凭空增加的收入。消费按在世人口和实际医教开销，另计资产维护。余钱先抵欠账，再留存；必要时可卖出生产资产。主角从自己的产出中分出的私钱在公用收入中扣除一次。

当前户完整推进。仍有人居住的出生户、手足户及姻亲户做基本收支和健康结算，重要亲属继续有个人经历。仅在婚配或手足成家时建立相关户。配偶独居且并入已有家庭时，将其明确配置的财物转入一次，移除空壳。分户不转移旧债。出生户优先由在场且有能力的父亲掌家，其次母亲。其余户按主角、指定家庭角色和已成年的子女顺位接手。仅剩未成年人的家庭继续供养并保留欠账，掌家人暂空。

无人户先用自有现金抵欠账。尚有资产、现金或余债时休眠，只保留余额；不计年产、不消费、不自动追索亲属。无余额与义务后移出年度家计集合，仅记关闭年份，保留亲属、遗产记录及年谱。休眠户仍可接受既有事件明确产生的还款。缺乏有据的后续处置时可持续休眠。此版本不另造无人田产买主、监护人委任程序或法律数据库。

## 四个复现入口

Node 22.18+ 或 24 运行 node scripts/household-runs.mjs。docs/household-runs.json 保存结果。A、C 从正常出生起逐年推进，一律选首项。B、D 为明确构造的测试边界，使用正式婚谈、清算与年度结算函数。

- A：debt3，15岁原家欠71钱、现金为零，这次读书未成。
- B：separate0，旧家有200钱和500钱债；支出6钱婚费后，旧家留194钱、欠500钱，新户有39钱、无债。
- C：debt2，主角36岁时父亲去世，主角与手足各得3钱；母亲接掌旧家，14岁的晚辈仍在，56钱家债留在旧户。
- D：cleared-house，无在世成员，私产清算完毕，户中7钱偿清7钱欠账；次年没有进入家计结算，三位亲属的记录仍在。

22项既有测试及3项新增成员与关闭测试均通过。原有同种子求学分支验收改用 pair28；年度经济公式变化后，旧例 pair6 的两条路在40岁落到了同一职业。另以512局首选项策略重新运行债务诊断，逐步核对契债与遗产分配。505人活到5岁。既有死亡参数保持原值。
