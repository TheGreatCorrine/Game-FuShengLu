# 西汉切片 · Phase 2A.1 基线审计

## 怎么复核

同一组 quality0 至 quality599 在四套选择策略下各回放一次。出生样本数为 600，策略轨迹数为 2,400。旧引擎取 dd46480，使用当前 scripts/phase2a1.mjs 作为同一观测器，以 esbuild 打包后用 Node 执行。完整旧表见 PHASE_2A_1_BEFORE.md，修复后的同口径表见 PHASE_2A_1_AFTER.md。在已安装依赖的项目根目录可执行：

```sh
node_modules/.bin/esbuild scripts/phase2a1.mjs --bundle --platform=node --outfile=/tmp/fsl-cohort.cjs
node /tmp/fsl-cohort.cjs > /tmp/fsl-cohort.jsonl
python3 scripts/summarize-phase2a1.py < /tmp/fsl-cohort.jsonl
```

## 家计与婚议

首选策略下，5、15、25、40、60 岁存活者所在户的负债率分别为 35.1%、73.6%、56.9%、76.7%、74.9%。此前观察的方向可重现，具体百分比不同。25 岁佃作出身者有债比例 96.6%，行商出身者 8.1%。出身与机会、资产、同住人口同时变化；组间差距不能单独证明某项系数的因果作用。家计设计表提供健康两成人两孩的无灾算例，用于隔离基本用度和劳动产出的缺口。需要分别测童年用度、少年劳动和老年停工的影响。

565 人活到初婚窗口。首选策略下 373 人收到提议，117 人曾婚；其中女性初婚中位数 25 岁，男性 26.5 岁。未重现早前报告的 31/29。随机策略有 57 人曾婚。教育策略会反复优先见面，保守策略会优先缓议；两者都未提交成婚回帖。因此不能用这两组的零婚率估算愿意成婚者的成功机会。统计中的“活到可婚”仅表示存活到年龄窗口，未扣掉冷却期或资金不足的年份。回帖失败是事件次数，曾婚是人数。

## 角色与事件

资格、机会与结果应分开观察。40 岁的资质分组同时受求学机会和存活选择影响。连续低健康年只是行动受限的近似指标。照护消耗下一年工时，健康还会影响学习和谋生；职业变化的计数包括年龄转换时的初次定业。家庭、健康和身份的逐项读取点见 design 下四张表。

现有界面已将四项账目移入详情。婚议缓办、患病参与者、具名长辈和配偶转业已有用例。检查 work 的所有入口时发现三项语义错配：留下分担生计、辍学回家、婉拒核账，都会抽取与受雇相同的三钱报酬。本次移除此额外支付，保留学习状态、实作及关系变化。其余明确提到受雇的选择保留原报酬模型；不同工作的定价仍待设计。

## Phase 2B 人物线提案

先试两条现有目标：积谷、传艺。复用具名 NPC、目标、记忆及职业。由当事人提出计划 → 家计或健康形成障碍 → 当事人按能力及既往承诺采取行动 → 同一人在下次相遇中回应结果。允许放弃、延期和自行完成。例如配偶想织作，得到资助后转业；再次见面时能说明谁资助过，以及是否因此缓解家计。玩家拒绝时，角色仍可另寻机会。验收用同种子两条分支核对人物 ID、开支、职业与后续回忆，人物志只展示可观察的关系印象。2C 再扩展跨地区见闻与职业入口。
