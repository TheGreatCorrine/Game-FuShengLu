# 人物与抉择验收

运行 npm test（31项）、npm run build 和 node scripts/character-runs.mjs。独立 HTML 已在禁用 fetch 的 DOM 环境实际完成取名、推进、选项、终章和重开，未在手机实机复核。旧回归仍包括512局按步检查；新诊断用另外256个种子，首次议亲先会面，之后一律选首项。实际事件计数与逐项输出见 character-runs.json。

- A，受控 fathers0：同样的25钱、欠3钱、同一请求与随机抽取。愿教字的张安拿出书简，应允入学；重积谷而较少愿意出资的张安要求次日到工。
- B，自然 character2：26岁见做文书的朱宁。选择先谈用度，29岁再议时仍是同一人，保留 meeting 记忆。她/他的姓名、工作和目标可用原记录核查。
- C，自然 character29：30岁时，积谷的配偶周成提出转行。资助会扣本人三钱、转织作；同一存档改选劝阻，周成仍自主接活，留下争执记忆。
- D，受控 memory12：20岁修屋照应或去挣钱，同一人五年后面对相同的10钱欠账。前者应允动用私蓄，后者拒绝。该对照固定中间家计和接触，测试记忆与关系共同影响的结果。

本期不追求模拟所有职业方案。配偶换业目前集中于织作。照料占用时间按年度折算；手足独户为本人已有积蓄的简化场景。婚议未定者只推进年龄及健康，成为伴侣后才完整模拟家计。人物是否真正容易辨认仍须真人盲测。下一阶段建议让玩家分别试玩一次亲人拒绝、一次折中、一次自行决定，复述当事人为什么这么做，再决定是否补其他职业与说法。
